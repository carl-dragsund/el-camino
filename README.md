# El Camino accommodation map

An interactive map of Camino routes and places to stay, with photo galleries, available price notes, route filters, and listing links.

Once the first GitHub Pages deployment completes, open the map at:

https://carl-dragsund.github.io/el-camino/

The site deploys automatically from `main` using the workflow in `.github/workflows/pages.yml`. It uses Leaflet, IGN route and map services, and photos hosted by accommodation listing sites.
